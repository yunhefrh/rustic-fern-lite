# rustic-fern-lite

Software engineer @cncf

学习用的示例项目

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 安装

```bash
git clone https://github.com/USER/rustic-fern-lite.git
cd rustic-fern-lite
chmod +x run.sh
```
